# alexanderwebber.com

Spec-driven project built with [Spec Kit](https://github.com/github/spec-kit) and the
[sdd-playbook](https://github.com/alexwebber/sdd-playbook) house standards. Read the project
memory (what's next, working norms) and the constitution before doing any work:

@PROJECT_MEMORY.md
@.specify/memory/constitution.md

Start each session with `/session-start`. Decisions so far, with their reasons, are in
`DECISIONS.md`: search it when a past choice matters, and add each new decision at its end as it's
made. Deferred/future work lives in `BACKLOG.md`.

Before CI, framework or hosting work, read the matching section of the playbook's
[`AGENT_TIPS.md`](https://github.com/alexwebber/sdd-playbook/blob/main/AGENT_TIPS.md) (local:
`C:\Projects\sdd-playbook\AGENT_TIPS.md`).
