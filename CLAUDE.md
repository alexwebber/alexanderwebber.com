# alexanderwebber.com

Spec-driven project built with [Spec Kit](https://github.com/github/spec-kit) and the
[software-factory](https://github.com/alexwebber/software-factory) house standards. Read the project
memory (what's next, working norms) and the constitution before doing any work:

@PROJECT_MEMORY.md
@.specify/memory/constitution.md

Start each session with `/session-start`. Decisions so far, with their reasons, are in
`DECISIONS.md`: search it when a past choice matters, and add each new decision at its end as it's
made. Deferred/future work lives in `BACKLOG.md`.

Before CI, framework, hosting or other technical work, load the matching house-process topic
skill (`speckit-house-process-tips-<topic>`: shell, secrets, git, github-actions,
privacy-pipelines, providers, research, windows-cloud, astro, testing, maps, share-images, docs,
cloudflare, ui-accessibility). Briefs for subagents name the ones their tasks need.
